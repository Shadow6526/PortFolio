# Project hover videos

Drop an MP4 or WebM file here named after the project's `metadata.id`:

- `orbis.mp4`
- `cf-dashboard.mp4`
- `federated-learning-p2p.mp4`

The Projects carousel auto-matches the filename, so no code edit is needed.
The project screenshot stays visible by default and acts as the video poster.
The video is muted, loops, and plays only while the card is hovered; leaving
the card pauses and rewinds it.
